## About The Project

This repository contains the source code for my interactive portfolio. It is designed to act as a centralized hub for my cybersecurity writeups, software engineering projects, and certifications. 

### Key Sections:
- **Interactive Terminal Hero**: Animated typing effect highlighting my dual-focus in cybersecurity and frontend dev.
- **Project Timeline**: Detailed breakdown of my major projects including the Distributed Monitoring Pipeline (SOC Honeypot) and Marks Dashboard.
- **Skills Matrix**: Auto-scrolling and interactive "bubble" displays of my languages, security tools, and platforms.
- **Live Contact Form**: Fully functional client-side form using EmailJS and DOMPurify for sanitization.

---

## Tech Stack

This project is built to be lightweight and fast, requiring no backend build steps for deployment:

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Styling**: Tailwind CSS (via CDN) & Custom Neon CSS Variables
- **Animations**: [tsParticles](https://particles.js.org/) (interactive background), pure CSS keyframes
- **Functionality**: EmailJS (Serverless contact form), DOMPurify (XSS prevention)
- **Deployment**: Vercel / GitHub Pages ready

---

## Running Locally

Since this is a static website without a build step, running it locally is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/vikalp1817243/portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your web browser. 
   *(Alternatively, use the VS Code "Live Server" extension for hot-reloading).*
